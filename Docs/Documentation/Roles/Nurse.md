# Role: Nurse (`nurse`)

**Display name:** Nursing Staff  
**PPT slides:** 1–2

---

## Purpose

Support bedside / ward care: **vitals**, **nursing notes**, **medication administration**, **shift handover**, and **emergency alerts**.  
Nurse does **not** do billing or doctor prescriptions.

---

## Main tools

| Tool | What nurse does |
|------|-----------------|
| Patient vitals | Record BP, pulse, temp, etc. |
| Nursing notes | Care notes linked to patient/appointment |
| Medication administration | Record giving medicines |
| Shift handover | Hand over pending tasks to next shift |
| Emergency alerts | Raise / update / escalate alerts |
| Profile & notifications | Own profile, alerts |

---

## Key actions allowed

- View patients and OPD context  
- Create / update vitals and notes  
- View lab (read)  
- Medication view / create / update  
- Handover create / update / submit  
- Emergency alert create / update / escalate  

## Not for this role

- Collect payment  
- Book / cancel appointment  
- Complete doctor consultation  
- Dispense pharmacy stock (pharmacist)  

---

## Typical flow for PPT

1. Identify patient from ward / appointment context  
2. Record vitals and nursing notes  
3. Administer medication as ordered  
4. Raise emergency alert if needed  
5. Submit shift handover at end of duty  

---

## Permissions (summary)

`patients:view`, `opd:view`, `lab:view`,  
nurse vitals / notes / medication / handover / emergency alerts,  
nurse profile & notifications
