# Role: Super Admin (`super_admin`)

**Display name:** Super Admin / Hospital Owner  
**PPT slides:** 1

---

## Purpose

Highest authority for **one hospital**: staff control **plus** roles, hospital settings, audit, and policy-level features.  
Separate panel from Hospital Admin.

---

## Two panels (important for PPT)

| Panel | Who | Focus |
|-------|-----|-------|
| **Hospital Admin** (`/admin/`) | Manager | Staff + dashboard |
| **Super Admin** (`/super-admin/`) | Owner / director | Full control |

Same hospital. Not multi-hospital SaaS.

---

## Main tools

| Tool | What super admin does |
|------|------------------------|
| Everything Admin can do | Staff + dashboard |
| Roles & permissions | Create / assign (policy) |
| Hospital settings | Fees, org settings |
| Audit log | Who changed what |
| Reports | Hospital-level |

---

## Message for PPT

> Admin runs day-to-day staff.  
> Super Admin owns the system configuration.

---

## Typical flow for PPT

1. Define roles / permissions  
2. Configure hospital settings  
3. Oversee staff and audit  
4. Review reports
